# 🔬 연구실에서 살아남기 (lab-survival)

장비를 두들겨 데이터를 뽑고 논문을 쓰고 연구비를 따서 연구실을 키우는 3D 웹게임.

▶ 플레이: https://lab-survival.vercel.app

## 조작
- 화면을 드래그하면 조이스틱처럼 이동
- 가까이 가면 자동으로 행동
- 🏛 학과 탭에서 강의 · 세미나 · 과제 지원

## 랭킹
